# My Tasks 📝

A simple To-Do List app built with **React Native** and **TypeScript**.

## Features

* Add new tasks
* Mark tasks as completed
* Delete completed tasks
* Save tasks locally with AsyncStorage
* Restore tasks when reopening the app

## Technologies

* React Native
* TypeScript
* AsyncStorage
* React Hooks
* FlatList

## Installation

```bash
npm install
npm install @react-native-async-storage/async-storage
```

For iOS:

```bash
cd ios
pod install
cd ..
```

Run the app:

```bash
npm run ios
```
